アプリ集 v2（レシピ追加版）

【使用可能】
・わくわく抽選
・食材レシピメーカー入口

【食材レシピメーカー】
・児童用ページを開く
・先生用／レシピ管理ページを開く
・児童配布用URLをコピー

【今後追加予定】
・児童用「公開中／公開終了」の切り替え
・出席
・評価

【Netlify更新】
このフォルダをそのまま既存サイトのDeploysへドラッグ＆ドロップしてください。
